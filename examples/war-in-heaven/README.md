# Пример: «Война в Раю»

Рассказ Юрия (2014, 2026; около 9 000 слов: пролог, шесть глав и послесловие), собранный скиллом [`ebook-build`](../../ebook-build/SKILL.md) этого репозитория.
Всё, что нужно для сборки, лежит здесь: главы в Markdown, `book.json`, обложка и сады.

| Файл | Что это |
|---|---|
| `главы/` | Текст: по файлу на главу, первая строка — `# Заголовок` |
| `book.json` | Всё о книге: порядок глав, три части, аннотация, фрагмент, сады и три режима сборки |
| `материалы/cover.jpg`, `материалы/make_cover.js` | Обложка 1600×2560 и скрипт, который её рисует: сад с seed 7 выращивает движок из `js/dist` |
| `gardens/` | Сады шмуцтитулов (`part1–3.png`) и украшения глав (`chapters/`): их рисует `make_gardens.py` |
| `книги/` | Готовые книги |
| `снимки/` | Снимки страниц для README |

## Пересобрать

```bash
bash ../../ebook-build/scripts/setup_env.sh
python3 ../../ebook-build/scripts/make_gardens.py --config book.json
python3 ../../ebook-build/scripts/build_book.py --config book.json --all-modes
```

Последняя команда собирает три режима и проверяет каждую книгу: 112 проверок, 0 предупреждений, 0 ошибок; проза во всех режимах совпадает слово в слово.
